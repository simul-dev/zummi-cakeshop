# 쩜미 케이크샵

컨베이어 벨트로 나오는 케이크 접시를 4×5 테이블에 배치해서, 같은 맛 조각 6개를 모아 케이크를 완성하는 모바일 웹 퍼즐 게임.

## 실행

```bash
npm install
npm run dev
```

- PC: http://localhost:5173
- 휴대폰: 같은 Wi-Fi에서 터미널에 찍히는 `Network` 주소(예: `http://192.168.x.x:5173`)로 접속

배포용 빌드는 `npm run build` → `dist/` (상대 경로라 아무 정적 호스팅에 올려도 동작).

## 규칙

- 시작할 때 테이블 4×5 칸 중 랜덤한 곳에 2~4조각짜리 접시가 몇 개 깔린다. **이후로 테이블에 저절로 생기는 접시는 없다.**
- 하단 컨베이어에 1~4조각짜리 접시가 3개씩 나온다. **지금 테이블에 있는 맛으로만** 나오고, 맛마다 (테이블 + 컨베이어) 조각 수가 6의 배수가 되도록 모자란 만큼을 우선 채운다. 그래서 잘 놓기만 하면 항상 테이블을 비울 수 있다.
- 접시를 테이블 빈칸에 놓으면 **상하좌우로 붙은 접시끼리 같은 맛 조각이 한 접시로 모인다.**
- 한 접시에 같은 맛 6조각이 모이면 케이크 완성 → 커졌다가 사라지며 점수 획득 (연쇄 시 콤보 배수).
- 어떤 맛이 테이블에서 다 사라지면, 컨베이어에 남은 그 맛 접시는 다른 접시로 바뀐다.
- **테이블을 전부 비우면 클리어** → 다음 단계(시작 접시·맛 종류가 조금씩 늘어남). 테이블이 꽉 차면 실패.

## 조작 (모바일 우선)

- **드래그**: 접시를 끌어서 놓기. 터치일 때는 손가락에 가리지 않도록 접시가 손가락 위로 떠서 따라오고, 가장 가까운 빈칸에 자석처럼 붙는다.
- **탭-탭**: 접시를 탭해서 고른 뒤 빈칸을 탭.
- 안드로이드는 진동 피드백, 효과음은 WebAudio 합성(🔊 버튼으로 끄기).

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/config.ts` | 밸런스 값 (조각 수, 단계별 시작 접시 수/맛 종류 등) |
| `src/game.ts` | 게임 상태, 합치기·완성·클리어 판정, 컨베이어 생성, 드래그 상태 |
| `src/cake.ts` | 접시/케이크 조각 의사 3D 렌더링 (조합별 스프라이트 캐시) |
| `src/flavors.ts` | 케이크 6종 색/장식 정의 |
| `src/scene.ts` | 배경 (케이크샵 내부, 테이블, 컨베이어) |
| `src/render.ts` | 프레임 렌더링, 이펙트, 튜토리얼 |
| `src/input.ts` | 포인터 입력 |
| `src/layout.ts` | 화면 크기별 레이아웃 |
| `src/hud.ts`, `index.html`, `src/style.css` | 점수/게임오버 UI |

### 합치기 규칙 세부

놓인 접시(와 변화가 생긴 접시)마다, 같은 맛을 가진 이웃 중 **그 맛을 가장 많이 모을 수 있는 접시**로 조각을 모은다. 동점이면 원래 테이블에 있던 접시, 그다음 다른 맛이 덜 섞인 접시를 고른다. 이동은 "같은 맛의 뭉침 정도(접시별 개수 제곱합)"가 늘어날 때만 허용해서, 조각이 두 접시 사이를 오가는 무한 루프가 생기지 않는다.
